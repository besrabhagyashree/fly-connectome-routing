# Reading library

Downloaded 2026-09-17. All files are open-access (Nature OA / eLife / bioRxiv / arXiv).
Where only a paywalled or unlinkable journal version exists, the preprint is saved instead (marked "preprint").

## Suggested reading order
1. **06 Shiu 2024**: the whole-brain spiking model (start here; laptop-runnable)
2. **07 Lappalainen 2024**: connectome + task training predicts neural activity
3. **01 Dorkenwald 2024**: the FlyWire connectome itself
4. **10 Bates 2026 (BANC)**: brain + nerve cord, key for brain→body work
5. **17 Vaxenburg 2025** and **18 Wang-Chen 2024**: the virtual fly bodies
6. **19 Eon 2026** and **20 Jin 2026**: the latest embodied / AI-controller work
